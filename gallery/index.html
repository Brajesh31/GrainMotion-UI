GrainMotion-UI

Twenty-four tactile controls made of sand that moves like sand. Rake it, push a stone through it, select, write, track progress, step through a workflow and watch an hourglass. Each component is a standalone file with no runtime dependencies.

The repo on GitHub ↗

The sand is simulated: every groove, heap and ripple is a height field that slumps to its angle of rest, lit on the GPU. Sound plays after your first touch; GrainMotionUI.Sound.on = false turns it off.
